larghezza fissa della finestra). Vanno benissimo per guide e sito; per il
pixel-perfect Windows restano preferibili le catture native, da mettere nella
cartella superiore `docs/assets/screenshots/`.

Nessun dato reale: nessun token valido, nessun chat ID reale, nessun percorso personale.
