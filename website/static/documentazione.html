Il file CSV dei segnali

È l'unico punto di contatto fra BetRelay e il tuo software: BetRelay scrive una riga, il software la legge e decide se scommettere. Queste sono le 14 colonne che BetRelay produce, nell'ordine in cui compaiono nel file.

Telegram → parser → segnali.csv → XTrader / Betting Toolkit → CSV svuotato
Formato

📄 Come è fatto il file

Nomi delle colonne sulla prima riga, tutti i valori fra doppi apici, codifica UTF-8 con BOM. Una sola riga attiva alla volta: dopo il timeout il file torna a contenere solo l'intestazione.

Riconoscimento

🎯 Per id o per nomi

Il software può individuare la selezione dagli id Betfair (MarketId + SelectionId) oppure dai nomi (EventName + MarketType + SelectionName). Con il metodo a nomi la lingua della fonte deve corrispondere a quella con cui il software legge il palinsesto.

Lato scommessa

↔️ PUNTA / BANCA

BetRelay scrive PUNTA (back) e BANCA (lay). XTrader e Betting Toolkit accettano indifferentemente PUNTA/BANCA e BACK/LAY in tutte le versioni: non c'è nulla da convertire.

# Colonna Che cosa contiene
1ProviderNome della fonte dei segnali. Il software può filtrare le strategie per provider, quindi tienilo stabile.
2EventIdId dell'evento nel palinsesto Betfair.
3EventNameNome dell'evento, es. «Sporting Lisbon v Braga».
4MarketIdId del mercato nel palinsesto Betfair.
5MarketNameNome del mercato, es. «Esito Finale».
6MarketTypeTipo di mercato nella nomenclatura Betfair (MATCH_ODDS, OVER_UNDER_25…). Identico in tutte le versioni del software.
7SelectionIdId della selezione nel palinsesto Betfair.
8SelectionNameNome della selezione, es. «Il Pareggio».
9HandicapServe per i mercati asian handicap. Vale 0 quando non si applica.
10PriceQuota da usare per la scommessa (facoltativa). La strategia può usarla o ignorarla.
11MinPriceQuota minima perché il segnale sia considerato valido.
12MaxPriceQuota massima perché il segnale sia considerato valido.
13BetTypePUNTA (back) oppure BANCA (lay).
14PointsMoltiplicatore dello stake, usato solo se la strategia attiva l'opzione relativa. BetRelay lo lascia vuoto.
Perché il CSV viene svuotato.

Una fonte di segnali con aggiornamento automatico rilegge il file a ogni ciclo: se BetRelay lasciasse la riga vecchia sul disco, il software la rimetterebbe in lista anche dopo che l'hai cancellata a mano. Per questo, passato il timeout, BetRelay riporta il file a sola intestazione — è la garanzia che nessun segnale di ieri diventi una scommessa di oggi.
